# Festival de Artes da Estaca Pirituba

Projeto final do curso WDD 131.

## Como abrir

1. Abra a pasta `festival_artes_projeto` no VS Code.
2. Use o Live Server no arquivo `index.html`.
3. Mantenha a estrutura de pastas exatamente como está.

## Imagens

As imagens atuais são provisórias e estão otimizadas em formato WebP.
Você pode substituí-las posteriormente por fotografias reais, mantendo os mesmos nomes dos arquivos:

- `festival-hero.webp`
- `jovens-apresentacao.webp`
- `teatro.webp`
- `musica.webp`
- `danca.webp`
- `logo-festival.webp`

Antes de publicar fotografias identificáveis de jovens, confirme as autorizações necessárias e atualize `referencias.html`.

## Arquivos principais

- `index.html`: página inicial
- `programacao.html`: programação dinâmica e filtros
- `prepare-se.html`: orientações, checklist e formulário
- `confirmacao.html`: confirmação do formulário e contador
- `referencias.html`: créditos e referências
